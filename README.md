# Post Comment — 再設計版（開発中）

講義・イベントのコメント投稿ルームをPHPとSQLiteで運用するシステムです。

> **現在は初期実装段階です。** DBスキーマ、初回管理者セットアップ、管理者ログインの基盤まで実装しています。既存の投稿機能・ルーム管理・フォームビルダー・CSV・移行・GitHub自動更新は**未実装**です。既存サービスの置き換えには使用しないでください。

## 基本方針

- PHP + PDO_SQLITE。root権限、SSH、Composerのサーバー実行、cronは必須にしない。
- SQLiteにルーム・ユーザー・コメントを一元化。ルームごとにPHPやDBテーブルを複製しない。
- 個人認証あり／なしをルーム別に選べる。認証ありは全ルーム共通IDとシステム発行コード。
- 参加者用CSVはタイムスタンプとコメントのみ。管理者用はフォーム回答全体。
- `5dlab_old` は移行対象外。

## 開発段階の起動方法（安全な環境のみ）

**重要:** Web公開ディレクトリ（DocumentRoot）には `public/` **だけ**を指定してください。 `config.php`、`src/`、`database/`、`storage/` をWebから参照可能な位置に置かないでください。DocumentRootを変更できない環境向けの安全な配布形態は今後実装します。

1. PHP 8.3+ と PDO_SQLITE が使用可能な環境を用意。
2. `config.example.php` を `config.php` にコピー。
3. `config.php` に `installation.setup_key` を追加し、32文字以上の暗号学的にランダムな値を設定。セットアップ終了後も公開しない。
4. `storage/` をPHPが書き込み可能な非公開領域に配置。
5. HTTPSで `public/` を開き、`?route=setup` から初回管理者を作成する。

PHP組み込みサーバーでのローカル動作確認例（**本番利用不可**）:

```sh
php -S 127.0.0.1:8080 -t public
```

本番運用可能と判断するには、保存先のロック・公開領域・権限、セッション設定、更新やバックアップの検証が必要です。
