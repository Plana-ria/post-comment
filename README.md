# Post Comment — 再設計版（開発中）

講義・イベントのコメント投稿ルームをPHPとSQLiteで運用するシステムです。

> **現在は初期実装段階です。** DBスキーマ、初回管理者セットアップ、管理者ログイン、ルーム作成、ユーザーID・コード、標準フォームでの投稿、CSV出力の初期版まで実装しています。フォーム編集・複数管理者の初期画面、ログイン試行制限、管理画面からのDBバックアップ取得、管理者認証情報の再発行を追加しましたが、旧データ移行、バックアップ復元、GitHub自動更新、レンタルサーバー向け完成版の配布は**未実装**です。既存サービスの置き換えには使用しないでください。

## 基本方針

- PHP + PDO_SQLITE。root権限、SSH、Composerのサーバー実行、cronは必須にしない。
- SQLiteにルーム・ユーザー・コメントを一元化。ルームごとにPHPやDBテーブルを複製しない。
- 個人認証あり／なしをルーム別に選べる。認証ありは全ルーム共通IDとシステム発行コード。
- 参加者用CSVはタイムスタンプとコメントのみ。管理者用はフォーム回答全体。
- `5dlab_old` は移行対象外。

## 開発段階の起動方法（安全な環境のみ）

**重要:** Web公開ディレクトリ（DocumentRoot）には `public/` **だけ**を指定してください。 `config.php`、`src/`、`database/`、`storage/` をWebから参照可能な位置に置かないでください。DocumentRootを変更できない環境向けの安全な配布形態は今後実装します。

1. PHP 8.3+ と PDO_SQLITE が使用可能な環境を用意。
2. `config.example.php` を `config.php` にコピー。
3. `config.php` の `installation.setup_key` に、32文字以上の暗号学的にランダムな値を設定。セットアップ終了後も公開しない。
4. `storage/` をPHPが書き込み可能な非公開領域に配置。
5. HTTPSで `public/` を開き、`?route=setup` から初回管理者を作成する。

PHP組み込みサーバーでのローカル動作確認例（**本番利用不可**）:

```sh
php -S 127.0.0.1:8080 -t public
```

本番運用可能と判断するには、保存先のロック・公開領域・権限、セッション設定、更新やバックアップの検証が必要です。

## 管理画面の運用機能（開発中）

- `?route=operations`：システム管理者のみ利用可能。SQLiteの整合性を確認したバックアップをダウンロードする。
- `?route=operations`：システム／ルーム管理者の認証情報を再発行する。旧認証情報は無効となる。
- `?route=db-upgrade`：既存DBに未適用のマイグレーションがある場合、システム管理者がバックアップ後に更新する。
- バックアップには参加者の個人情報・ログイン認証情報のハッシュを含む。ダウンロードしたファイルの共有・保管には注意すること。

**バックアップのブラウザ復元はまだ未実装です。** 非エンジニア向け運用の完成条件を満たしていないため、現段階で本番導入しないでください。
