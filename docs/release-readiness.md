## CIで確認する項目

`php tests/smoke.php` でDB・フォーム・認証・CSV・バックアップ・復元・署名付きZIPの基本処理を試験する。 `python3 tests/http_smoke.py` で初回セットアップ、ログイン、投稿、本人CSV、管理者CSV、新着API、管理者権限分離などをHTTPで確認する。

CIが全成功しても、上の必須項目を自動的に完了扱いにはしない。
