## 必須の未完了確認

- [ ] 本番と同等の共有レンタルサーバーで、DocumentRootを変更できない場合も含め設置・ファイル権限を確認

- [ ] 旧 `post-comment.zip` 全ルーム（`5dlab_old` を除く）の実フォーム・文言・案内表示を個別照合
- [ ] 旧MySQL実データまたは正式全件CSVからの本番相当移行、行数・時刻・特殊項目を突合
- [ ] 旧CSVの文字コード・BOM・カンマ・改行を含むコメントを検証
- [ ] DB更新前バックアップ、更新途中の書込失敗、ZIP破損、署名不一致の障害注入試験
- [ ] 更新失敗時のコード・DB復旧と、復旧不能時の保守画面操作を実機で検証
- [ ] GitHub Releasesの署名用秘密鍵をGitHub secretに登録し、公開鍵を安全に配布・設定
- [ ] 正式リリースZIPと署名ファイルの作成・ダウンロード・検証・更新を本番相当環境で試験
- [ ] 共有ホスティングでの並行投稿、匿名Cookie期限、管理者の同時フォーム更新を確認
- [ ] 認証・権限・XSS・CSRF・CSVインジェクション・アップロードのセキュリティ監査
- [ ] サーバー移設（ドメイン・ディレクトリ変更）とDB復元後の再ログイン・ルームURLを検証
- [ ] 日本語マニュアルを非エンジニアに試用してもらい、迷わず一連の操作が可能か検証

## CIで確認する項目

`php tests/smoke.php` でDB・フォーム・認証・CSV・バックアップ・復元・署名付きZIPの基本処理を試験する。 `python3 tests/http_smoke.py` で初回セットアップ、ログイン、投稿、本人CSV、管理者CSV、新着API、管理者権限分離などをHTTPで確認する。

CIが全成功しても、上の必須項目を自動的に完了扱いにはしない。
